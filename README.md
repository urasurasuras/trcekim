# TRÇekim

Website for TRÇekim, a school-event photography and videography service. Parents view
their child's event gallery with an access code and order prints. The photographer
manages schools, events, uploads and orders.

This repository revives the original 2012–2016 site (kept in `legacy/` for reference)
as a .NET Blazor Web App that ships as a Docker image.

- `docs/features.md`: the feature list and milestones
- `docs/legacy-analysis.md`: how the old site worked
- `CLAUDE.md`: stack decisions and conventions
